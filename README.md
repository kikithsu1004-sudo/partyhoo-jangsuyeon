# 파티후 장수연 랜딩페이지

## 가장 쉬운 배포 방법
1. GitHub에서 새 저장소를 만듭니다.
2. 이 ZIP 안의 파일을 저장소 최상단에 모두 업로드합니다.
3. Settings → Pages → Deploy from a branch를 선택합니다.
4. Branch를 `main`, 폴더를 `/ (root)`로 지정하고 Save 합니다.
5. 생성된 공개 주소를 네이버 블로그, 인스타그램 프로필, 문자 상담 등에 사용합니다.
